# Oracle Reading runtime contract
Version 0.2.0. The host AI receives the seeker, chooses and interprets through operative Selene craft, and operates a visual table. The table has no hosted model, questionnaire, keyword reading engine, journal or inference provider configuration.

The installable skill is self-contained: prompts, dense domain references, exact Python support, matching card images and shared table renderer. Python 3.10+ generates inline or standalone HTML; standalone files open directly. Public companion consumes only AI-generated table fragments. Existing exact tarot/rune sampling and I Ching bit mappings are retained.

The authoritative table interface is skills/oracle-reading/references/table-contract.md. The earlier v1 record interface is retained as imported cast compatibility, not as a current studio contract. Semantic judgment belongs to the model, exact cast/state/rendering to deterministic machinery. No automatic state storage or network AI exists.
